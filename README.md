# Once Coronas — La guerra por Kaedra

Estrategia en tiempo real en 3D para Windows.

**Descargar:** [OnceCoronas-Windows.zip](descargas/OnceCoronas-Windows.zip). Descomprime la carpeta y abre `OnceCoronas.exe`
(no necesita instalación). El juego se actualiza solo desde este repositorio.

- `actualizaciones/manifiesto.json`: versión publicada y novedades.
- `actualizaciones/resources.neu`: el juego empaquetado que descarga el actualizador.
